# Agent project guidance

Do not rewrite published Lovable-linked history.

## Design quality workflow
- For UI tasks read root `PRODUCT.md` and `DESIGN.md` before writing code.
- Apply Taste Skill, Impeccable and Awesome DESIGN.md references *within the existing product brand*, never by copying competitor visuals.
- Preserve existing Lovable git history, routes, data contracts, auth/roles and regulatory gates; no force push.
- Check UI through existing tests/build, an advisory `npx --yes impeccable@4.8.0 detect src/`, plus real screenshots and keyboard access on mobile/desktop.
